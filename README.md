# Python AI Code Sandbox Runner

This Python script demonstrates a basic sandbox runner for executing untrusted code. It uses `subprocess` to isolate code execution in a separate process with a timeout, preventing it from affecting the main system.

## Language

`python`

## How to Run

Run this script using `python sandbox_runner.py` in your terminal.
